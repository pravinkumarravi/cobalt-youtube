## Key Findings from Reverse Engineering

### Architecture Discovery

YouTube TV (Fire TV Edition)
- Application Class: dev.cobalt.app.CobaltApplication
- Main Activity:     dev.cobalt.app.MainActivity
- Engine:            Cobalt (Google web-app engine for TV)
- App URL:           https://www.youtube.com/tv
- Splash URL:        file:///youtube_splash_screen.html
- Native Library:    libcobalt.lz4 (compressed Cobalt engine)
- GMS Integration:   com.google.android.gms (Sign-In, Auth)

### CRITICAL INSIGHT
This is NOT a traditional native Android app.
YouTube TV is a Cobalt-powered web app that loads https://www.youtube.com/tv 
in a custom browser engine. The UI is rendered as HTML/CSS/JavaScript.

## Recommended Recreation Approach

### Option A: True Clone (Cobalt-style Web Wrapper) - RECOMMENDED
Build a native Android TV shell that loads a custom YouTube TV-style web interface.

Tech Stack:
- Android TV (Leanback) + WebView wrapper
- Custom web UI (HTML/CSS/JS) served locally or remotely
- ExoPlayer for video playback
- YouTube Data API v3 for content

### Option B: Fully Native Android TV App
Build a 100% native Android TV app that replicates the UI pixel-perfectly.

Tech Stack:
- Kotlin + Jetpack Compose (TV edition) or Leanback
- ExoPlayer / Media3
- YouTube Data API v3
- Retrofit + OkHttp for networking
